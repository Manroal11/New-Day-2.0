# New Day 2.0 — Project Overview

## Purpose

New Day 2.0 is a professional public website and management platform for the New Day NGO. It will help people understand the organization’s work and give authorized staff a reliable place to publish updates and manage program information.

## Brand foundation

- **Organization:** New Day
- **Developer:** Man & Tech
- **Tagline:** Empowering People. Building Futures.
- **Growth Green:** `#245B42`
- **Sunrise Gold:** `#F0B84C`
- **Warm Canvas:** `#F8F6EF`
- **White:** `#FFFFFF`
- **Dark Ink:** `#24342D`

## Technology

- Next.js App Router and React
- TypeScript
- Tailwind CSS
- ESLint
- npm
- Supabase is planned for a later integration phase; no Supabase project or credentials are part of Phase 0.
- Vercel CLI is planned for a later deployment phase; this initialization does not deploy the site.

## Phase 0 scope

Set up the application foundation, brand tokens, a responsive under-development homepage, and project documentation. No dashboard workflows, authentication, database, or public content publishing are implemented in this phase.

## Local development

From the `new-day-v2` project folder, run `npm run dev`, then open [http://localhost:3000](http://localhost:3000). See the root README for the available npm scripts.
